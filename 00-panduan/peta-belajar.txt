Cara pakai file ini:
- Belajar sesuai urutan. Jangan melompat ke fase berikutnya sebelum
  fase sekarang selesai.
- Tiap hari buka folder "hari-NN-..." lalu baca "catatan.txt",
  jalankan "index.html" di browser, dan KETIK ULANG kodenya sendiri.
- Setelah selesai satu hari, ubah tanda [ ] menjadi [x] di daftar ini.
- Kalau bingung, ulangi hari sebelumnya. Tidak masalah untuk lambat.

PENTING (alur ketiga folder):
  HTML  -> kerangka/isi halaman
  CSS   -> tampilan/warna/tata letak

Ketiganya dipakai bersama. Materi dipisah per folder agar mudah dicari,
tetapi pada akhirnya (hari 34) semuanya digabung dalam satu project.
