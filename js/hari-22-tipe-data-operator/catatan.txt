- Menggunakan template literal untuk menyusun teks.
- Mengecek tipe data dengan typeof.

[2] TEORI SINGKAT
Tipe data adalah "jenis" dari sebuah nilai. Tipe dasar di JavaScript:
- string : teks, ditulis di dalam tanda kutip, contoh "Halo" atau 'Halo'.
- number : angka, baik bulat maupun desimal, contoh 25 atau 12.5.
- boolean: hanya true atau false.
- null   : nilai kosong yang sengaja kita isi.
- undefined: variabel yang ada tetapi belum diberi nilai.

Operator aritmatika: + - * / % (sisa bagi) dan ** (pangkat).
Operator perbandingan menghasilkan true/false: > < >= <= === !==.
Operator logika: && (DAN), || (ATAU), ! (BUKAN/negasi).

Penting: gunakan === (sama persis, cek nilai dan tipe) daripada == (cek nilai saja).
Contoh: 5 == "5" bernilai true, tetapi 5 === "5" bernilai false karena tipenya beda.

Template literal memakai backtick (`) sehingga kita bisa menyisipkan nilai dengan ${...}.
Contoh: `Halo ${nama}`.

Kesalahan umum: menulis angka di dalam tanda kutip sehingga menjadi string ("5"). Akibatnya "5" + 1 menghasilkan "51", bukan 6.

[3] ANALOGI
Tipe data itu seperti wadah berbeda di dapur. Gelas (number) untuk air, kotak (string) untuk tulisan, saklar (boolean) hanya punya dua posisi: nyala atau mati. Kamu harus memakai wadah yang tepat agar hasilnya benar.

2. Hitung luas (panjang * lebar) dan simpan di variabel luas.

[7] RINGKASAN
- Lima tipe dasar: string, number, boolean, null, undefined.
- typeof dipakai untuk melihat tipe sebuah nilai.
- Operator aritmatika menghitung, perbandingan menghasilkan boolean.
- Gunakan === untuk membandingkan, hindari ==.
- Template literal `${...}` memudahkan menyisipkan nilai ke teks.
