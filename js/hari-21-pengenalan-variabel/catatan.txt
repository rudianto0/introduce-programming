===============================
HARI 21 - Pengenalan Variabel
Estimasi: 30 menit
===============================

[1] TUJUAN HARI INI
- Mengenal apa itu JavaScript dan perannya di halaman web.
- Menampilkan pesan dengan console.log() dan ke halaman.
- Membuat variabel dengan let dan const (serta mengenal var).
- Mengikuti aturan penamaan variabel dengan benar.

[2] TEORI SINGKAT
HTML adalah kerangka, CSS adalah tampilan, sedangkan JavaScript adalah "otak" yang membuat halaman menjadi hidup: bisa menghitung, bereaksi, dan berubah.

console.log("pesan") menampilkan pesan ke Console browser. Buka dengan menekan F12 lalu pilih tab Console.

Variabel adalah wadah untuk menyimpan nilai. Ada tiga cara membuatnya:
- let  : nilainya boleh diubah.
- const: nilainya tidak boleh diubah (untuk nilai tetap).
- var  : cara lama. Sebaiknya dihindari karena bisa membingungkan.

Contoh:
let umur = 20;
const nama = "Budi";

Aturan penamaan variabel:
- Boleh huruf, angka, _ dan $, tetapi TIDAK boleh diawali angka.
- Tidak boleh ada spasi. Gunakan camelCase, misalnya namaLengkap.
- Tidak boleh memakai kata kunci seperti let, const, function.
- JavaScript membedakan huruf besar/kecil: umur dan Umur adalah dua variabel berbeda.

Kesalahan umum pemula: lupa memberi tanda kutip pada teks, atau menulis let dua kali untuk variabel yang sama. Ingat juga: const tidak boleh diisi ulang.

[3] ANALOGI
Variabel itu seperti kotak berlabel. Kamu menuliskan label pada kotak (nama variabel) lalu memasukkan isi ke dalamnya (nilai). "let" ibarat kotak yang isinya boleh diganti, sedangkan "const" ibarat kotak yang isinya sudah dikunci.

[4] KODE CONTOH
- index.html: berisi judul, paragraf penjelasan, dan elemen <p id="output"> sebagai tempat menampilkan hasil. Di akhir body ada <script src="script.js"></script> agar file JS ikut dijalankan saat halaman dibuka.
- script.js:
  * console.log(...) menampilkan nilai ke Console.
  * let age untuk variabel yang isinya diubah.
  * const name untuk variabel yang tidak diubah.
  * var oldStyle sebagai contoh cara lama.
  * document.getElementById("output") mencari elemen HTML, lalu .textContent mengganti isi teksnya.

1. Buat variabel kota dengan let, isi dengan nama kotamu.
2. Buat variabel tahunLahir dengan const.
3. Tampilkan keduanya di Console memakai console.log.
4. Ubah nilai kota menjadi nama kota lain, lalu tampilkan lagi.
5. Tampilkan kalimat "Saya dari <kota>" ke elemen #output memakai textContent.

[6] TANTANGAN (5 menit)
Hapus tanda // pada baris yang mengubah nilai const name. Apa pesan error yang muncul di Console? Jelaskan mengapa error itu terjadi.

[7] RINGKASAN
- JavaScript membuat halaman web menjadi interaktif.
- console.log() untuk melihat nilai di Console (F12).
- Gunakan let untuk nilai yang berubah, const untuk nilai tetap.
- Hindari var di kode baru.
- Ikuti aturan nama variabel dan perhatikan huruf besar/kecil.

[8] PERSIAPAN BESOK
Besok kita belajar tipe data (string, number, boolean, null, undefined) dan operator.
