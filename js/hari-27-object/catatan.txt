HARI 27 - Object
Estimasi: 30 menit
===============================

[1] TUJUAN HARI INI
- Membuat object dengan pasangan key: value.
- Mengakses properti dengan dot dan bracket.
- Membuat method dan memahami this.
- Mengenal nested object dan destructuring.
- Memakai Object.keys dan Object.values.

[2] TEORI SINGKAT
Object menyimpan data dalam bentuk pasangan key: value di dalam kurung kurawal:
const siswa = { nama: "Rudi", umur: 18 };
- "nama" adalah key (kunci), "Rudi" adalah value (nilai).

Ada dua cara mengakses:
- Dot notation : siswa.nama
- Bracket notation: siswa["nama"] atau siswa[kunci] (dipakai saat key disimpan di variabel).

Method adalah fungsi di dalam object:
perkenalan: function () { return `Halo ${this.nama}`; }
Kata this merujuk ke object itu sendiri.

Nested object artinya object di dalam object, contoh siswa.alamat.kota.

Destructuring mengambil nilai ke variabel: const { nama, umur } = siswa;

Object.keys(obj) mengembalikan daftar key, Object.values(obj) daftar nilai.

Kesalahan umum: menulis siswa.nama padahal key memiliki spasi (harus pakai bracket), dan lupa bahwa this bergantung pada bagaimana fungsi dipanggil.

[3] ANALOGI
Object itu seperti KTP. Ada beberapa kolom: nama, tanggal lahir, alamat. Setiap kolom punya nama (key) dan isi (value). Kita bisa meminta isi kolom dengan menyebut namanya: "alamat" -> "Jakarta".
