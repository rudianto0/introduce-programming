[1] TUJUAN HARI INI
- Membuat keputusan dengan if / else if / else.
- Memakai switch untuk banyak pilihan pasti.
- Menulis if/else singkat dengan ternary.
- Memahami konsep truthy dan falsy.

[2] TEORI SINGKAT
Kondisi membuat program bisa memilih jalur. Struktur if menjalankan blok kode hanya jika kondisinya true:
if (nilai >= 90) { ... } else if (nilai >= 80) { ... } else { ... }

switch cocok saat kita membandingkan SATU nilai dengan banyak nilai pasti. Jangan lupa break agar tidak "jatuh" ke case berikutnya:
switch (hari) { case "Senin": ...; break; default: ...; }

Ternary adalah bentuk singkat if/else yang menghasilkan nilai:
const status = umur >= 17 ? "Boleh" : "Tidak boleh";

Truthy dan falsy: ada nilai yang dianggap "salah" (falsy), yaitu false, 0, "", null, undefined, dan NaN. Semua nilai lain dianggap "benar" (truthy).

Kesalahan umum: memakai = (penugasan) padahal maksudnya === (perbandingan). Contoh if (x = 5) selalu true dan malah mengubah nilai x. Juga sering lupa break di switch.

[3] ANALOGI
Kondisi itu seperti rambu di persimpangan. Jika lampu hijau, jalan; jika kuning, hati-hati; jika merah, berhenti. Ternary itu seperti memilih cepat "makan atau tidak?" dalam satu tarikan napas.

[7] RINGKASAN
- if / else if / else untuk memilih jalur berdasarkan kondisi.
- switch untuk banyak pilihan pasti, ingat break.
- Ternary = if/else singkat yang menghasilkan nilai.
