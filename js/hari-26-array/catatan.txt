HARI 26 - Array

[1] TUJUAN HARI INI
- Membuat dan mengakses array.
- Menambah/menghapus item dengan push, pop, shift, unshift.
- Mengubah dan menyaring data dengan map dan filter.
- Mencari data dengan find dan includes, serta menggabungkan dengan join.

[2] TEORI SINGKAT
Array adalah daftar berurutan, ditulis di dalam tanda kurung siku:
const angka = [10, 20, 30];
Nomor urutnya (index) dimulai dari 0, jadi angka[0] adalah 10.

Menambah/menghapus item:
- push(x)    : tambah di akhir.
- unshift(x) : tambah di awal.
- pop()      : hapus item terakhir.
- shift()    : hapus item pertama.

Metode penting:
- length   : jumlah item.
- map(fn)  : ubah setiap item, hasilnya array BARU.
- filter(fn): simpan item yang lolos uji, hasilnya array BARU.
- find(fn) : ambil item PERTAMA yang lolos uji.
- includes(x): cek apakah ada (true/false).
- join(sep): gabung semua item menjadi satu string.

Kesalahan umum: mengira index mulai dari 1. Padahal item pertama adalah index 0. Juga sering lupa bahwa map dan filter mengembalikan array baru, bukan mengubah array asli.

[3] ANALOGI
Array itu seperti rak buku berurutan. Kamu bisa menaruh buku di ujung depan (unshift) atau belakang (push), mengambilnya (pop/shift), dan mencatat daftar judulnya (join). map itu seperti menempel stiker baru ke setiap buku, filter itu memilih hanya buku tertentu.
