Hobi dan Rencana Pengembangan Diri

Hobi Favorit Saya

  • Membaca buku self-improvment untuk memperluas wawasan
  • Mengikuti kursus online grammar Bahasa Inggris untuk mengasah kemampuan bahasa
  • Belajar membuat website dan mengeksplorasi dunia pemrograman

Rencana Belajar

  1. Menyelesaikan satu bab buku pengembangan diri setiap minggu
  2. Meningkatkan pemahaman Bahasa Inggris
    • Menonton video materi tata bahasa (grammar) dari kursus online
    • Mengerjakan latihan soal tenses dan struktur kalimat
  3. Mempelajari dasar-dasar HTML, CSS, dan JavaScript
  4. Membangun proyek website portofolio pertama secara mandiri

Istilah Penting

Self-Improvment
Proses sadar untuk meningkatkan kualitas diri, baik dari segi mental, keterampilan, maupun pola pikir.
HTML (HyperText Markup Language)
Bahasa standar yang digunakan untuk merancang dan menyusun struktur halaman web.
