===============================
HARI 19 - Responsive
Estimasi: 30 menit
===============================

[1] TUJUAN HARI INI
- Mengingat kembali fungsi meta viewport.
- Menulis media query untuk mengubah tampilan sesuai lebar layar.
- Menerapkan pendekatan mobile-first.

[2] TEORI SINGKAT
Halaman yang baik harus nyaman dibuka di HP maupun komputer. Ini disebut
responsive.

Langkah penting:
1. Meta viewport di <head>:
   <meta name="viewport" content="width=device-width, initial-scale=1.0">
   Tanpa ini, HP akan menampilkan halaman versi kecil lalu di-zoom.
2. Media query, yaitu aturan bersyarat berdasarkan lebar layar:
   @media (min-width: 600px) { ... }
   Artinya: "bila layar minimal 600px, pakai aturan di dalamnya."
3. Mobile-first: tulis dulu gaya untuk HP (satu kolom), lalu naikkan jumlah
   kolom untuk layar yang lebih besar dengan min-width.

Pakai max-width pada container agar teks tidak melebar berlebihan di layar
besar, dan width: 100% agar menyesuaikan layar kecil.

[3] ANALOGI
Responsive itu seperti menata meja makan.
- Di ruang sempit (HP), kursi disusun satu-satu berbaris.
- Di ruang besar (komputer), kursi disusun banyak ke samping.
Media query adalah aturan: "kalau ruangannya cukup lebar, tata begini."

[4] KODE CONTOH
Pada style.css:
- .container memakai width: 100% dan max-width: 900px, margin: 0 auto agar
  konten di tengah dan tidak terlalu lebar.
- .grid secara default (mobile) memakai grid-template-columns: 1fr, jadi
  kartu bertumpuk satu per satu.
- @media (min-width: 600px) mengubah grid menjadi 2 kolom.
- @media (min-width: 900px) mengubahnya menjadi 4 kolom.
- Coba perkecil dan perbesar jendela browser untuk melihat perubahannya.

[5] LATIHAN (10 menit)
Ketik sendiri:
1. Ubah ambang batas media query pertama menjadi 500px.
2. Ubah jumlah kolom pada 600px menjadi 2 dan pada 900px menjadi 3.
3. Kecilkan jendela browser sampai di bawah 500px, amati kartu bertumpuk.
4. Tambahkan kartu kelima di index.html dan pastikan tetap rapi.
5. Ubah padding .container pada layar kecil menjadi 16px.

[6] TANTANGAN (5 menit)
Buat media query max-width: 500px yang mengubah text-align .hero menjadi
left. Jelaskan mengapa pendekatan mobile-first lebih mudah daripada
menulis gaya desktop dulu.

[7] RINGKASAN
- Meta viewport wajib agar halaman tampil pas di HP.
- Media query @media (min-width: ...) mengubah gaya sesuai lebar layar.
- Mobile-first: gaya HP dulu, lalu tambah aturan untuk layar lebih besar.
- max-width pada container menjaga konten tetap nyaman dibaca.
